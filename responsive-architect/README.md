# Responsive Architect

## Project Overview

A responsive frontend interface demonstrating mobile-first design, semantic HTML5, CSS3, CSS Grid, Flexbox and Vanilla JavaScript.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Design System

- Mocha Mousse (`#A47864`)
- Ethereal Blue (`#A0D4E0`)
- Moonlit Grey (`#F2F0EA`)
- Dark Text (`#2F2925`)
- Muted Text (`#6F6964`)

## Responsive Strategy

Mobile-first architecture.

- **Tablet**: 768px
- **Desktop**: 1024px
- **Wide Desktop**: 1440px – 1920px

## Architecture

- Semantic HTML5
- CSS Grid for macro layouts
- Flexbox for component layouts
- Vanilla JavaScript for interaction
